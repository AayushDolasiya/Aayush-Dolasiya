# Personal Portfolio | Neo-Brutalist Web Developer

Welcome to the repository for my personal portfolio! This project is a full-stack MERN application designed with a unique Neo-Brutalist aesthetic to showcase my engineering skills, projects, and professional journey.

## 🔗 Live Demo
**Check out the live site here:** [https://my-portfolio-ochre-tau-49.vercel.app/]

---

## 🛠️ Tech Stack
*   **Frontend:** React.js
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB
*   **Deployment:** Vercel
*   **Styling:** Neo-Brutalist Design System (Custom CSS / Tailwind)

---

## ✨ Features
*   **Striking UI/UX:** High-contrast, bold typography, and distinct borders designed to stand out to recruiters and clients.
*   **Project Showcase:** Dedicated sections highlighting my full-stack applications (including my YouTube Script Generator and Expense Management app).
*   **Responsive Design:** Fully optimized for a seamless experience on desktop, tablet, and mobile.
*   **Contact Integration:** Backend-connected contact form to easily handle professional inquiries.
